Lesson 1 • Tách cấu hình ra khỏi code
2. Đọc Cấu Hình Vào Spring Bean: @Value vs @ConfigurationProperties
Cách 1: Dùng @Value (Lấy từng thuộc tính lẻ)
@RestController
@RefreshScope
public class OrderController {

    @Value("${order.discount:10}")
    private int discount;

    @GetMapping("/config")
    public String getDiscount() {
        return "Discount: " + discount + "%";
    }
}
Cách 2: Dùng @ConfigurationProperties (Theo nhóm)
// Tự động ánh xạ mọi cấu hình có tiền tố "order.*"
@Component
@ConfigurationProperties(prefix = "order")
public class OrderProperties {

    private int discount;
    private String message;

    // Getter & Setter
}
Tiêu chí so sánh @Value("${key:default}") @ConfigurationProperties(prefix = "...")
Phạm vi áp dụng Đọc 1 – 2 biến cấu hình đơn lẻ Ánh xạ cả một cụm cấu hình (Object, List, Map)
Kiểm tra dữ liệu (@Validated) Không hỗ trợ Hỗ trợ kiểm tra @Min, @Max, @NotBlank lúc khởi động
Cập nhật động (Khi Refresh) Bắt buộc gắn thêm @RefreshScope Tự động re-bind giá trị mới không cần @RefreshScope
Lesson 2 • Lưu trữ cấu hình bằng Git
3. Tổ Chức Kho Cấu Hình Trên Git (Git Config Repository)
🛠️ Khởi tạo Git Config Repo để Demo
# 1. Tạo thư mục & khởi tạo Git

# 2. Nội dung file order-service-dev.yml

Lesson 3 • Cài đặt Config Server và Client
5. Cài Đặt Spring Cloud Config Server (Port 8888)
1. Khai báo Dependency & Class Chính
<!-- pom.xml -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-config-server</artifactId>
</dependency>
@SpringBootApplication
@EnableConfigServer // Kích hoạt Config Server
public class ConfigServerApplication {
    public static void main(String[] args) {
        SpringApplication.run(
            ConfigServerApplication.class, args);
    }
}
2. Cấu hình application.yml của Config Server
server:
  port: 8888

spring:
  application:
    name: config-server
  cloud:
    config:
      server:
        git:
          # Dùng Git Local hoặc link GitHub
          uri: file:///C:/demo/config-repo
          default-label: main
          clone-on-start: true
Lesson 3 • Cài đặt Config Server và Client
6. Cài Đặt Config Client (Order Service - Port 8081)
1. Khai báo Dependency (pom.xml)
<!-- Biến Microservice thành Config Client -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-config</artifactId>
</dependency>

<!-- Hỗ trợ /actuator/refresh ở Lesson 4 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
2. Cấu hình application.yml của Client
server:
  port: 8081

spring:
  application:
    name: order-service  # Khớp tên file trên Git
  profiles:
    active: dev          # Khớp hậu tố -dev
  config:
    import: "optional:configserver:http://localhost:8888"

management:
  endpoints:
    web:
      exposure:
        include: refresh, health
Lesson 4 • Tự động cập nhật cấu hình
7. Làm Mới Cấu Hình Không Cần Restart Với @RefreshScope
1. Gắn @RefreshScope vào Controller
@RestController
@RefreshScope // Tái tạo lại Bean khi có lệnh refresh
public class OrderController {

    @Value("${order.discount:10}")
    private int discount;

    @GetMapping("/config")
    public String getDiscount() {
        return "Discount: " + discount + "%";
    }
}
2. Kích hoạt làm mới qua Actuator
# Gửi HTTP POST tới Order Service (:8081)
curl -X POST http://localhost:8081/actuator/refresh
// JSON trả về danh sách các thuộc tính vừa đổi:
[
  "config.client.version",
  "order.discount"
]
